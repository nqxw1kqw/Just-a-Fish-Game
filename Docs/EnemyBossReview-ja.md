# 敵・ボスの点検と提出前の方針

対象は現在のソースです。今回の変更後、戦闘の手動プレイやフレーム時間の計測はまだ実施していません。ビルド成功とメニューの描画確認は、難易度や実測性能の保証とは分けて扱います。

## 今回修正した項目

| 対象 | 問題 | 対応 |
|---|---|---|
| 通常敵 | 再利用するスロットのスタン・高度・前回の描画位置が残る可能性 | 出現時に構造体を初期化し、出現位置で補間を開始 |
| 突進型 | 予告線が固定 280、実際の移動距離は速度×3.2×0.65秒 | 予告線と接近終了距離を実際の突進距離に統一 |
| 経路 | 通常敵向けの経路を大型ボスにも使用 | 半径 24 / 55 / 75 / 100 を基準に 4 種類の経路を共有 |
| クジラ | 地上の接近が岩へ直進 | 体格に合う経路を使用 |
| サメ・イカ | 旋回や横移動で岩に押し付けられる場合がある | 自由移動時だけ前方の障害物を避ける方向を選択 |
| カジキ | 遠距離でも回転斬りを選び、攻撃が届かない場合がある | 攻撃半径＋回転中の移動距離＋プレイヤー半径以内で選択 |

経路と回避は固定配列を使用します。攻撃予告が終わった後のロック方向は追尾させず、回避可能な予告を維持します。

## 現在の技構成の評価

| ボス | 役割 | 提出前の判断 |
|---|---|---|
| クジラ | 大波、飛び込み、尾撃、泡の網、吸い込み、群れ召喚、潜行 | 技数は十分です。追加より予告と攻撃判定の一致を優先します。 |
| サメ | 噛みつき、旋回、渦、潜砂からの狩り | 対応方法が異なる技が揃っています。拘束中と投げた直後の安全性を重点的に確認します。 |
| イカ | 触手、墨の散布、墨弾、捕獲 | 遠距離役として成立しています。墨と触手の予告が重なる場面の視認性を確認します。 |
| カメ | 回転突進、噛みつき、尾撃、甲羅破壊 | 甲羅破壊後の反撃時間が役割になります。岩への衝突後も休息が確実に入るかを確認します。 |
| カジキ | 直線突進、回転斬り、怒りの潜砂 | 機動力が役割です。今回は距離に応じた技選択を修正し、攻撃数は増やしません。 |

## 後で検討する項目

- 通常敵同士の分離は現在も全組み合わせの比較です。多数出現時に実測で重いと分かった場合、空間分割を導入します。
- 長い拘束演出、広範囲エフェクト、大量の敵が重なる場面は、実プレイで見やすさと待ち時間を確認します。
- 体力・ダメージ・予告時間の一括変更は、通しプレイの結果を見て行います。

提出までの優先順位は、不具合修正、日本語表示の統一、配布物の整理です。
