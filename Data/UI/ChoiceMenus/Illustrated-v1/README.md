# イラスト版の選択メニュー

## 画像

| ファイル | 用途 |
|---|---|
| `language.png` | 英語・日本語を併記した言語選択画面 |
| `mode-en.png` | ノーマル／ハード選択画面・英語 |
| `mode-ja.png` | ノーマル／ハード選択画面・日本語 |
| `PROMPTS.md` | 組み込み画像生成ツールに渡した原文 |

元画像は各 1672 × 941 px。ゲームでは 1600 × 900 px に合わせて表示します。背景、木枠、見出し、選択肢、ルール説明、決定ボタンの文字を画像に統合しています。言語選択は保存済みの言語に依存せず、常に同じ日英併記の画像を表示します。

選択カーソルには `Data/UI/Results/Illustrated-v1/selection-arrow.png` を共用し、上向きに回転して選択中のカードの下へ表示します。以前のイラストとメニューは、画像を読み込めない場合の代替表示として保持しています。

## 実装

`IllustratedChoiceMenu` が画像の読み込み、描画、マウス判定を担当します。`LanguageSelectScreen` と `ModeSelectScreen` から使用します。`GamePrototype` が既存のキー操作と画面遷移を管理します。

カード領域の元画像座標は、左 X=165～810、右 X=865～1505、上端 Y=215 です。下端は言語選択が Y=750、モード選択が Y=790。決定ボタンは X=520～1150、上端 Y=770／795、下端 Y=915 です。描画と入力で同じ解像度変換を使用します。

## 操作

- `A/D` または左右キー：選択。`W/S` または上下キーでも切り替え可能
- `Enter/Space`：選択中の項目を決定
- `1/2`：対応する項目で直接開始
- マウス：カード上へ移動して選択。同じカード上で左ボタンを押して離すと決定
- 下部の決定ボタンもクリック可能

画面へ入るたびにマウス入力を初期化し、保持したクリックが次の画面へ伝わることを防ぎます。停止したマウス位置はキーボードで変更した選択を上書きしません。

進行は「言語選択 → タイトル → チュートリアル → ノーマル／ハード選択 → 戦闘 → リザルト」です。言語選択画面では BGM を再生しません。ゲームバランス、チュートリアルの報酬引き継ぎ、記録形式は従来どおりです。
