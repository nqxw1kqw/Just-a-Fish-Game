# イラスト版リザルト画面

## 構成

| ファイル | 用途 |
|---|---|
| `lose-en.png` | 敗北画面・英語 |
| `lose-ja.png` | 敗北画面・日本語 |
| `win-en.png` | 勝利画面・英語 |
| `win-ja.png` | 勝利画面・日本語 |
| `selection-arrow.png` | 透過背景の選択カーソル |
| `PROMPTS.md` | 組み込み画像生成ツールに渡した原文 |

背景画像は 1672 × 941 px、ゲームでは 1600 × 900 px に拡大縮小して表示します。木枠、見出し、統計項目名、ボタンの文字は画像に描き込まれています。既存の承認済みイラストは別ファイルとして保持しています。

## 実行時の処理

`ResultScreen::Init()` で読み込み、`Shutdown()` で解放します。勝敗と現在の言語から背景を選びます。画像が欠けた場合は従来のリザルト画面を使用します。

点数・時間・撃破数・レベル・到達ステージを右側の空欄へ描画します。モード、最高記録、デバッグ使用の警告、再挑戦の開始位置など、プレイ内容に依存する情報は実行時の文字列です。スコア計算と記録ファイルの形式は従来どおりです。

値の列の中心は元画像の X=1370、行の中心 Y は 252 / 329 / 406 / 482 / 558 です。画像を作り直して配置を変更する場合は `ResultScreen.cpp` の座標も合わせてください。

## 操作

- `W/S` または上下キー：項目を選択
- `Enter/Space`：押してから離すと決定
- `R`：再挑戦、`T`：タイトルへ
- マウス：ボタンへ移動して選択、同じボタン上で左ボタンを押して離すと決定

入場直後の 0.6 秒は入力を受け付けません。戦闘中から保持していた決定キーやマウスボタンは、一度離してから新しく操作する必要があります。再挑戦は、そのプレイを開始したモードへ戻ります。通常のタイトルから開始した場合はチュートリアルからです。
