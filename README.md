# 躍る（Odoru） / Just a Fish Game

C++17 と DxLib で制作した、魚が主役の 3D アリーナ型サバイバル・ローグライトです。着地時の衝撃波で敵を倒し、カードで能力を強化します。

現在は提出用の日本語専用版です。タイトルから始まる一本道の冒険、分離画像のリザルト・ポーズ設定、障害物付きのローポリ海底モデルを統合しています。

| 項目 | 内容 |
|---|---|
| 開発環境 | Windows 10/11、Visual Studio 2022（v143）、x64 |
| 言語規格 | C++17 |
| 描画・入力・音声 | DxLib（x64） |
| 論理画面 | 1600 × 900 |
| 論理更新 | 固定時間刻み、120 Hz |
| 表示言語 | 日本語のみ |

## ゲームの進行

1. 日本語のタイトル画面から `Space` または `Enter` で開始します。
2. チュートリアルは各 15 秒の 3 ウェーブです。既存のカードを選びながら操作を覚えます。
3. チュートリアル終了後、カードを引き継いで通常ウェーブ 1 へ進みます。
4. 通常ウェーブは各 **25 秒**。敵が出現し、終了後は既存のカードを選びます。
5. **3 ウェーブごとに独立したボス戦**が入ります。ボス戦はウェーブを置き換えません。
6. 最初のボスは必ず **クジラ**。残るサメ・イカ・カメ・カジキは毎回ランダムな順序で、各 1 回ずつ出現します。
7. **合計 5 体のボスを倒すと勝利**です。通常ウェーブは合計 15 回です。
8. 体力がなくなると敗北します。再挑戦はチュートリアルから開始します。

| 通常ウェーブ | 直後のボス戦 |
|---|---|
| 1～3 | 第1戦：クジラ |
| 4～6 | 第2戦：残り4種からランダム |
| 7～9 | 第3戦：未登場のボス |
| 10～12 | 第4戦：未登場のボス |
| 13～15 | 第5戦：最後の未登場ボス → 勝利 |

カードの種類・効果・重ねがけ・選択方式は現在のものを維持しています。通常ウェーブ終了時は残りの敵を片付け、ボス撃破後は回復とカード選択を挟んで次のウェーブへ進みます。最終ボス撃破後はそのまま結果画面へ進みます。

経験値・レベル・経験値のドロップはありません。魚の能力は通常ウェーブ 4・7・10・13 の開始時に自動で強化されます。1区間ごとに、基礎値に対して最大体力 +20%、攻撃 +15%、移動速度 +4%、ジャンプ待ち時間 -5%、被ダメージ軽減 +4ポイントを加えます。カードの補正はそのまま加算されます。

敵はウェーブが進むほど出現間隔が短くなり、群れも大きくなります。同時生存数の上限はウェーブ1の12体からウェーブ15の40体まで増え、敵の種類ごとの出現コストにも制限があります。

[進行と実装の詳細](Docs/GameFlow-ja.md)を参照してください。

## 基本操作

| 場面・キー | 操作 |
|---|---|
| プレイ中の `W/A/S/D`・矢印キー | 魚を移動 |
| `Space` | ジャンプし、着地時に衝撃波を発生 |
| `Enter/Space` | 選択を確定 |
| カード選択中の `A/D`・左右キー、`1`～`3` | カードを選択・直接確定 |
| プレイ中の `Esc/P` | ポーズ・設定を開く／再開 |
| ポーズ中の `W/S`・上下キー | 項目を選択 |
| ポーズ中の `A/D`・左右キー | BGM・効果音の音量調整、画面モード切替 |
| ポーズ中のマウス | ボタンを選択、貝殻のつまみをドラッグして音量調整 |
| プレイ中・結果画面の `R` | 再挑戦 |
| 結果画面の `T` | タイトルへ戻る |
| `F1` / `F2` / `F10` / `F11` | デバッグ表示／カメラ振動／描画補間／情報パネルを切替 |

リザルトの画像ボタンはマウスでも操作できます。ポーズの `P` はデバッグ表示中はモデル調整用です。終了操作はウィンドウを閉じるか、ポーズ対象外の画面で `Esc` を押します。

背景、見出し、カード、魚、枠、ボタンを個別の PNG として描画します。固定の文字は画像内に含まれ、スコアなど変化する値は実行時に描画します。各 `layout.ini` を編集し、画面を開き直すと配置を更新できます。

- [以前の選択画面素材（保管用）](Data/UI/ChoiceMenus/Layered-v1/README.md)
- [勝利・敗北画面の素材と配置](Data/UI/Results/Layered-v1/README.md)
- [ポーズ・設定の素材と配置](Data/UI/Pause/Layered-v1/README.md)

各フォルダーの `PROMPTS.md` に組み込み画像生成ツールへ渡した原文を保存しています。リザルト用 PNG が不足した場合は、日本語の文字とパネルによる予備表示へ切り替えます。

## 日本語専用版の配布

言語選択画面、英語辞書、実行中の翻訳処理を外しています。日本語フォントだけを作成し、メニュー画像も日本語だけを読み込みます。キー名の `Space`、`Enter`、`W/A/S/D` などは実際のキーボード表記を使用します。

以前の英語用素材は保管しています。Release x64 をビルドしたあと、次のコマンドで日本語用の ZIP を作成できます。英語画像・使用しない難易度／言語選択用素材・旧ラテン文字フォント・個人の記録を除外します。出力先は `obj/Packages/Japanese-日時/` です。

```powershell
powershell -ExecutionPolicy Bypass -File Tools/package_japanese.ps1
```

## 敵とボスの調整

- 通常敵の再出現時は状態を初期化し、前の個体のスタン・高度・補間情報を引き継ぎません。
- 突進ザメは実際の速度と突進時間に合わせて予告線と攻撃開始距離を決めます。
- 障害物の経路を体格別の 4 種類に分け、大きなボスが小型敵用の狭い経路を選ぶ問題を抑えます。
- クジラの追跡、サメの旋回、イカの移動で障害物を避けます。予告後の突進方向は変更しません。
- カジキは回転攻撃で届く距離にいる場合に回転斬りを選択します。
- 新しい攻撃は増やさず、既存の予告・休息・同じ技の連続使用を抑える処理を維持しています。

[敵とボスの点検メモ](Docs/EnemyBossReview-ja.md)を参照してください。

## 海底モデル

`Data/Model/LowPoly/Floor.x` は砂、岩、サンゴ、貝殻、海草をまとめたローポリモデルです。面と法線は表向きに修正済みです。

- `Consts.h` の `FLOOR_USE_MODEL` でモデル表示を切り替えます。
- `FLOOR_MODEL_Y=-6` で起伏のある砂を水面より下へ置き、水面との交差を防ぎます。
- `FLOOR_MODEL_TINT_R/G/B` でゲーム内照明に合わせた色味を調整します。
- 中央の戦闘空間、四隅のサンゴ礁、左右の岩場、南北の崩れた石柱で構成しています。
- 14 個の岩・石柱に高さ付きの円柱判定があります。泳ぎ、ノックバック、通常敵、地上のボス移動に適用し、高さを超えるジャンプでは飛び越えられます。
- 移動・着地の地面は Y=0 のままです。岩の上には乗らず、岩に重なって着地すると縁へ押し出されます。サンゴの柔らかい枝、貝殻、海草は装飾です。
- 通常敵は共有の経路マップで岩を迂回します。突進する敵、カメ、カジキは障害物に当たると突進を終了し、サメの噛みつき突進は衝突でスタンします。潜砂・空中移動は高さに応じて通過します。
- 弾、衝撃波、ボスの範囲攻撃は従来どおり地形を通過します。岩は移動用の障害物です。
- モデルの読込・描画に失敗した場合は砂テクスチャ、次に箱とグリッドへ切り替えます。

[海底モデルの再生成方法](Tools/LowPolyModels/README_floor.md)を参照してください。Python の標準ライブラリのみで生成できます。

## 音声と保存データ

`SoundManager` が BGM のフェード、効果音の同時再生、音量を管理します。`Data/Sound/SE/` に基本の BGM・プレイヤー効果音・ボスなどの効果音を収録しています。音声が不足した場合はその再生を省略します。ポーズの音量は実行中の設定です。

- 以前の言語設定 `Data/settings.ini` は読み込まず、日本語で起動します。
- 現在の冒険の記録：`Data/highscore_campaign.dat`
- 以前のノーマル／ハードの記録は残しますが、現在の結果画面には混ぜません。

記録には到達ステージ、撃破数、生存時間、スコアを含みます。デバッグ機能を使用したプレイは記録しません。保存先は実行ファイルの隣の `Data` フォルダーです。これらの個人設定・記録やビルド生成物は Git に含めません。

## ビルドと起動

1. DxLib の x64 版を `C:\DxLib\` に配置します。別の場所を使う場合は、環境変数 `DXLIB_DIR` に末尾の `\` を含むパスを設定します。
2. `FishGame.sln` または `FishGame.vcxproj` を Visual Studio 2022 で開きます。
3. `Debug` または `Release`、`x64` を選んでビルドします。
4. 実行ファイルと同じ場所に `Data` フォルダーを置いて起動します。

```powershell
msbuild FishGame.vcxproj /p:Configuration=Debug /p:Platform=x64
.\FishGame_debug.exe
```

`Release` の実行ファイルは `FishGame.exe` です。最新の統合版は `main` にあります。
