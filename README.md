# 躍る（Odoru） / Just a Fish Game

**C++17 と DxLib で制作した、3D アリーナ型サバイバル・ローグライトです。**

プレイヤーは魚を操作し、敵の攻撃を避けながらジャンプします。着地時に発生する衝撃波で敵を倒し、ウェーブの合間にカードを選んで能力を強化します。

| 項目 | 内容 |
|---|---|
| 開発環境 | Windows 10/11、Visual Studio 2022（v143）、x64 |
| 言語規格 | C++17 |
| 描画・入力・音声 | DxLib（x64） |
| 画面解像度 | 1600 × 900 |
| 論理更新 | 固定時間刻み、120 Hz |

## ゲームの進行

### クラシック

5 ウェーブを突破すると、最終ボス「クジラ」との戦闘が始まります。各ウェーブ終了後に最大 HP の 30% が回復し、アップグレードカードを選びます。ウェーブの長さは進行に応じて 30～40 秒です。

### エンドレス

ウェーブが続き、敵の強さも上昇します。5 ウェーブごとにボスが出現します。各ウェーブは 35 秒で、ボスを倒すと最大 HP の 50% が回復します。最高到達ウェーブ、撃破数、生存時間を記録します。デバッグ機能を使ったプレイは記録されません。

### 基本操作

| キー | 操作 |
|---|---|
| `W` `A` `S` `D` / 矢印キー | 魚を移動 |
| `Space` | ジャンプし、着地時に衝撃波を発生 |
| タイトル画面の `1` / `2` | クラシック / エンドレスを開始 |
| タイトル画面の `W` / `S` | モードを選択 |
| カード選択中の `A` / `D` または左右矢印 | カードを選択 |
| カード選択中の `1`～`3` | カードを直接選択 |
| `Enter` | 選択を確定、またはタイトル画面から開始 |
| 結果画面の `R` | 最初から再開 |
| 結果画面の `T` | タイトル画面へ戻る |
| `F1` | デバッグ HUD の表示切り替え |
| `F2` | カメラ振動の切り替え |
| `Esc` | ゲームを終了 |

## 戦闘とアップグレード

- 地上では XZ 平面を移動し、ジャンプ中は空中制御で着地点を調整します。
- ジャンプ中はダメージを受けず、着地すると衝撃波で周囲を攻撃します。
- 通常敵はミニオン、ホッパー、タンク、浮遊型、突進型の 5 種類です。
- クラシックの最終ボスとエンドレスの定期ボスには、予告表示付きの範囲攻撃があります。
- アップグレードカードは 8 種類です。コモンカードは最大 3 回、「songdoi」は最大 2 回、「canoc」と最高レアカードは 1 回まで取得できます。
- カード画像が読み込めない場合は、英語名の画像を試し、それも見つからなければ代替表示に切り替わります。

## 音声データ

音声の読み込み、音量調整、効果音の同時再生、BGM のフェード切り替えは `SoundManager` が担当します。現在同梱している音声は次の 4 ファイルです。

- BGM: `Data/Sound/SE/game-loop-bgm.ogg`
- 効果音: `Data/Sound/SE/player-hit-se.mp3`
- 効果音: `Data/Sound/SE/player-jump-se.mp3`
- 効果音: `Data/Sound/SE/player-splash-se.mp3`

それ以外の音声は未同梱です。ファイルが見つからない音声は再生を省略するため、ゲームの起動は続行できます。

## ビルドと起動

1. DxLib の x64 版を `C:\DxLib\` に配置します。Visual Studio プロジェクトのインクルード先とライブラリ先はこのパスを参照します。
2. `FishGame.sln` または `FishGame.vcxproj` を Visual Studio 2022 で開きます。
3. 構成に `Debug` または `Release`、プラットフォームに `x64` を選び、ビルドして起動します。

PowerShell からビルドする場合:

```powershell
msbuild FishGame.vcxproj /p:Configuration=Debug /p:Platform=x64
.\FishGame_debug.exe
```

実行時は、`Data` フォルダーが実行ファイルから見える場所にある必要があります。ハイスコアはプレイ後に `Data/highscore.dat` へ保存されます。

## 主なファイル

| ファイル | 役割 |
|---|---|
| `main.cpp` | DxLib の初期化、120 Hz の固定更新ループ |
| `GamePrototype.cpp/.h` | ゲーム状態、ウェーブ進行、モード管理 |
| `PlayerFish.cpp/.h` | プレイヤーの移動、ジャンプ、着地攻撃 |
| `Enemy.cpp/.h` | 5 種類の敵、出現管理、衝突処理 |
| `Boss.cpp/.h` | クジラ型ボスと攻撃パターン |
| `CardManager.cpp/.h`、`CardDatabase.h` | カードの抽選、取得、能力反映 |
| `SoundManager.cpp/.h` | BGM、効果音、音量、フェード処理 |
| `Effects.cpp/.h`、`Bullet.cpp/.h` | パーティクル、衝撃波、弾 |
| `UIRenderer.cpp/.h` | HUD、タイトル、結果画面 |
| `CameraController.cpp/.h` | 3D カメラの追従と振動 |
| `DebugController.cpp/.h` | デバッグ操作と診断 HUD |
| `Data/` | 3D モデル、フォント、カード画像、音声 |

## 技術上の要点

- ゲームロジックを固定時間刻み 120 Hz で更新し、描画と分離しています。
- 敵、弾、効果音の再生ハンドルなど、繰り返し使う要素には固定長の配列を用います。
- 敵は最大 300 体まで管理します。自動射撃は初期設定で無効です。
- ハイスコアは `Data/highscore.dat` に保存します。この実行時ファイルやビルド生成物は Git の追跡対象外です。
