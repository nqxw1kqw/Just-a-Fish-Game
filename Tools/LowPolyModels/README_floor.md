# 海底モデルと障害物の生成

ゲームは `Data/Model/LowPoly/Floor.x` を読み込みます。`GameConsts::FLOOR_USE_MODEL` でモデル表示を切り替え、読み込みに失敗した場合は従来の床を使用します。その場合、障害物の移動判定も無効になります。

## 配置

- 中央は半径約 250 の広い戦闘空間です。
- 四隅には大きな岩とサンゴの群落、左右には低い岩を配置します。
- 北側の石柱は間隔 200 の門跡、南側は低い崩れた柱です。
- 中央から四方向への通路と、障害物の外側を回る経路を残しています。
- 海草と貝殻を群落の周辺へ配置し、砂には緩やかな帯状の色を付けています。

砂面には最大約 +5.5 の起伏があるため、ゲーム内では `FLOOR_MODEL_Y=-6` で水面の下に置きます。`FLOOR_MODEL_TINT_R/G/B` で照明に合わせて色味を調整します。水面の基準高は `SHALLOW_OCEAN_Y=0.55`、波の合計振幅は最大 0.44 です。

## 当たり判定

`floor_layout.py` の `ROCKS` がモデルと判定の共通の配置データです。生成時に `Floor.x` と `MapLayout.generated.h` を同時に書き出します。ヘッダーの上端はモデル座標で保存し、実行時に `FLOOR_MODEL_Y` を加えます。ヘッダーは直接編集せず、配置を変えて再生成・再ビルドしてください。

`MapObstacles` は 14 個の岩・石柱を円柱として扱います。ポリゴン単位の判定ではなく、見た目を囲む簡易判定です。サンゴの枝、貝殻、海草は通過でき、サンゴが生えた土台の岩だけが移動を遮ります。

- 移動区間を円に対して掃引し、衝突面に沿って滑らせます。高速移動とノックバックにも適用します。
- アクターの足元の高さが岩の上端を超える場合と、深く潜砂している場合は通過します。
- 地面は Y=0 です。岩の上に立つ機能はなく、重なった着地・出現は外周へ押し出します。複数の判定が重なる場所では、露出した境界を探します。
- 通常敵とボスは体格別に 4 種類の固定配列の 41×41 経路マップを共有し、約 0.2 秒ごとに追跡先を更新します。経路更新・移動判定で動的メモリを確保しません。
- 突進敵、カメの転がり、カジキの突進は衝突で終了します。サメの地上突進は衝突でスタンします。クジラの着地点は判定の外へ補正し、予告と着地で同じ位置を使います。
- 潜砂、空中移動、サメの拘束演出は専用の移動を維持します。弾・衝撃波・範囲攻撃は遮りません。

## 再生成

Python 3.10 以降の標準ライブラリだけで生成できます。Blender は不要です。リポジトリのルートから実行します。

```console
python Tools/LowPolyModels/build_floor.py
```

既定ではゲーム用のモデルと判定ヘッダーを同時に上書きします。別の場所へ書き出す場合は出力先を指定します。この場合、判定はモデルと同じ場所の `Floor.collision.h` に保存され、ゲーム用ヘッダーは変更しません。

```console
python Tools/LowPolyModels/build_floor.py --output Tools/LowPolyModels/out/Floor.x
```

`--collision-output` でヘッダーの保存先も指定できます。乱数シードは 7 で固定しています。`floor_mesh.py` が三角形、外向き法線、DirectX テキスト形式の出力を担当します。同梱モデルはこの生成スクリプトから出力したものです。
